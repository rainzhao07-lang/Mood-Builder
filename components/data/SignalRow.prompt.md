One physiological sensor reading. Stack several inside a `Card` on the Calibrate screen.

```jsx
<SignalRow label="Heart-rate variability" status="rest" statusText="Stable" value="72" unit="ms" />
<SignalRow label="Skin conductance" status="warn" statusText="Tracking" value="Low" />
```

Status tints only the dot + tag (rest = sage, warn = gold, alert = clay). Values are serif; keep them short.
